# Demo script (about 8 minutes)

Open the preview link. Saved data stays in your own browser, so run the steps in this order.

1. **Website**: home page. Drag the 3D photo carousel, hover the four level cards, slide the class finder, switch EN to SW in the top bar.
2. **Apply**: "Apply 2027" in the top bar. Fill a student and a parent name and phone, Continue twice, Submit. Note the reference number.
3. **Staff**: footer, "Staff sign in" (any email and password). Open **Admissions** in the sidebar: the application is there marked NEW. Click it, "Move to Interview".
4. **Akili AI** (sidebar):
   - *Results insights*: subject trends, students to support or stretch, topic gaps, suggested actions.
   - *Notes to lessons*: press "Draft lesson and questions" on the sample notes, then "Publish questions to students".
   - *Parent summaries*: pick a student, switch Kiswahili and English, approve.
5. **Akili Learn**: "Student view" (top right of Akili Studio). The teacher's topic is marked "New from your teacher". Open "Motion graphs": use a hint, answer, press "Eleza kwa Kiswahili", watch the mastery bars move and the next question come from the weakest objective.
6. **Control Centre**: Website pages, change the Home heading, Publish, then "View website".
7. **Parent Hub**: footer link. Tabs: Matokeo, Ada, Uliza.

Facts to say: the AI runs offline in this demo; in production it connects to the school database and a language model through the API in docs/API.md. Insights use example class data until real results are loaded.
